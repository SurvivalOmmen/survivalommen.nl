# Survivalvereniging Ommen

Website van **Survivalvereniging Ommen**.

De website is ontwikkeld als statische website en wordt gehost via **GitHub Pages** in combinatie met **Cloudflare Pages**.

---

## Pagina's

- Home (`index.html`)
- Over het initiatief (`over-survival-ommen.html`)
- Ik heb interesse (`interesse.html`)
- Contact (`contact.html`)
- Privacy (`privacy.html`)

---

## Formulieren

De formulieren op **Ik heb interesse** en **Contact** maken gebruik van hetzelfde Formspree-formulier.

**Formspree endpoint**

`https://formspree.io/f/mwvggwoa`

Na wijzigingen aan de formulieren altijd controleren of:

- berichten correct worden verzonden;
- berichten aankomen op `info@survivalommen.nl`;
- de succesmelding wordt weergegeven.

---

## Mappenstructuur

```text
assets/

```

---

## Publiceren

1. Wijzig de bestanden lokaal.
2. Upload de gewijzigde bestanden naar de GitHub-repository.
3. Commit de wijzigingen.
4. Cloudflare Pages publiceert de website automatisch.
